# Whitepaper publication policy

The SN87 whitepaper is not distributed from this repository. It will be added only as a
designated public release with an exact source version, checksum, license, and corresponding
implementation release.

Before adding a public whitepaper:

1. lock the release source and SHA-256 checksum;
2. reconcile its object names, message flow, privacy modes, oracle taxonomy, scoring semantics, limitations, and claim states with the repository's exact release commit;
3. audit repository history, issues, pull requests, Actions logs, artifacts, releases, dependencies, and rights;
4. verify that no private collaboration material, hidden challenge truth, Tenant Evidence, credentials, production topology, or proprietary material from other Provenonce projects is present;
5. confirm the whitepaper's own license and that it is consistent with the repository's MIT license (`LICENSE`); and
6. verify the published repository and document from an unauthenticated reader's perspective.

Repository visibility and whitepaper publication are separate evidenced actions. Neither is implied by development progress.
